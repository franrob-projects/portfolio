Writing Philosophy​

Great documentation doesn't just explain features - it helps users accomplish their goals. I believe in:

  • Testing everything - I verify every step before publishing
  • Knowing the audience - Different users need different information
  • Iterating based on feedback - Documentation is never "finished"
  • Writing for scannability - Users rarely read documentation linearly
